# 桌面贴图

[使用手册](../README.md) | [English](../../en/guide/pins.md) | **简体中文**

贴图将截图区域、剪贴板位图、本地图片、文本、HTML 片段或颜色值置顶悬浮在桌面上方，方便对照参考。所有贴图共用完整的 [标注编辑工具](annotations.md)，支持无损旋转、缩放、透明度调节、鼠标穿透、分组管理与关闭后恢复。

## 创建贴图的方式

1. **从截图生成**：截图界面按 `Ctrl+T` 或点击工具栏 `Pin` 按钮。
2. **从剪贴板或托盘创建**：运行 `clivuu paste` 或点击托盘菜单 `贴图剪贴板`。系统按如下优先级识别剪贴板内容：
   - 图片文件列表（最多 `32` 个文件）
   - 剪贴板位图图像
   - 非图片复制文件路径（默认跳过，关闭 `pin-text-skip-paths` 后生成路径文本贴图）
   - HTML 片段（转换受支持的行内格式，不发起外部网络请求；若纯文本本身是独立颜色值则转为色卡）
   - 原生颜色 MIME（`application/x-color`）与纯文本（最多 `40,000` 字符；独立颜色值如 `#bd93f9`、`#aarrggbb`、`rgb(255, 128, 0)` 或归一化浮点三元组自动转为可视化色卡）
3. **通过命令行指定来源**：
   - `clivuu paste --files DIR image1.png nested/image2.jpg`（参数中出现目录时，会更新后续相对路径的基准目录）
   - `clivuu paste --plain "纯文本原样显示"`
   - `clivuu paste --html "<b>富文本片段</b>"`
   - 搭配 `--pos X Y` 可指定贴图出现的屏幕逻辑坐标。
4. **拖拽导入与 `Ctrl+V` 原地替换**：将支持的文件或文本拖放到已有贴图上时，会在目标贴图位置生成新贴图并隐藏原贴图；若拖拽期间按住 `Shift`（或开启 `pin-preserve-drag=true`），则保留原贴图继续显示。聚焦某张贴图并按 `Ctrl+V` 时，若剪贴板为单项内容，会原地替换该贴图并保持其屏幕位置不变。

重复贴出相同来源的剪贴板或截图记录时，Clivuu 会前置匹配的原贴图并闪烁提示（若原贴图此前已关闭则会重新打开并保留已有标注）；剪贴板为空时调用 `clivuu paste` 不会有任何改动，仅返回 `{"pinned":0,"ids":[]}`（恢复已关闭贴图请使用 `clivuu reopen-pin`、`clivuu reopen-pins` 或托盘 `贴图恢复与清理` 菜单）。

## 鼠标手势与键盘编辑

默认贴图交互手势（可在 `首选项 -> 控制 -> 鼠标` 中修改）：

| 操作 | 默认手势 / 快捷键 |
| :--- | :--- |
| 移动贴图 | 鼠标左键拖动 |
| 按比例缩放窗口大小 | 拖拽边缘或角点 |
| 缩放大小 | 滚轮（支持启用 `+` / `-` 键同修饰符缩放） |
| 调整透明度（交互范围 `20%–100%`；默认配置 `10%–100%`） | `Ctrl + 滚轮`（或右键菜单 `−` / `+`） |
| 缩略图 / 还原切换 | `Shift + 双击左键`（或菜单 `缩略图 / 还原`） |
| 复制 OCR 或原始文本 | `Shift + 右键`（开启原位 OCR 时优先复制选中文本，否则复制源文本）或 `Ctrl+Shift+C` |
| 重置缩放与透明度 | 中键单击 |
| 关闭贴图（可恢复） | 双击左键、`Ctrl+W` 或 `Esc`（工具栏收起时） |
| 永久销毁贴图 | `Ctrl + 双击左键`、`Shift+Esc` 或菜单 `销毁贴图` |
| 打开右键菜单 | 鼠标右键 |
| 显示/隐藏标注工具栏 | `Space`（或菜单 `显示工具条`） |
| 应用变更并收起工具栏 | `Enter`、`Esc`（工具栏打开时）或 `Space` |

贴图获得键盘焦点且未激活标注绘图工具时可用的快捷操作：
- **`1` / `2`**：顺时针 / 逆时针旋转 `90°`
- **`3` / `4`**：水平 / 垂直翻转
- **`5`**：切换灰度显示滤镜（导出时同步生效且无损可逆）
- **`6`**：切换反色显示滤镜
- **`方向键`**：每次移动 `1` 个逻辑像素
- **`Alt`**：显示局部放大镜（配合 `Shift` 切换 RGB/HEX，`C` 复制像素色值），并在 OCR 文字选字模式下按住拖动贴图
- **`O`**：切换贴图上的原位 OCR 选字模式
- **`Ctrl+Shift+C`**：从文本、HTML 或色卡贴图复制原始未栅格化文字
- **`Ctrl+Shift+P`**：打开首选项窗口
- **`Ctrl+A`**：全选当前分组全部可见贴图，可批量移动、变换滤镜、合并复制/保存、关闭或销毁

## 右键菜单项

在贴图上单击右键可调用：

- `复制图像` / `保存图像` / `识别文字`（贴图处于 OCR 模式时按需显示 `复制选中文字` / `复制全部文字`）
- `粘贴`（从剪贴板创建新贴图或前置已有匹配贴图；原地替换聚焦贴图请按 `Ctrl+V`）
- `显示工具条`（展开完整标注与裁剪工具栏；其中 `裁剪` 固定 `1px` 强调色边框与圆环锚点，支持直接拖拽边缘/角点缩放、拖动内部平移已有裁剪区域及重新框选）
- `缩略图 / 还原`（折叠为缩略图或恢复原大小）
- `重置尺寸`
- `不透明度`（`−` / 点击百分比重置为 `100%` / `+`）
- `鼠标穿透`（开启鼠标穿透，穿透后可通过托盘菜单 `恢复鼠标交互` 或 `clivuu no-click-through` 恢复）
- `移动到贴图组`（将当前贴图或 `Ctrl+A` 选中的多张贴图移入现有分组、移动到新贴图组，或打开贴图组管理器）
- `关闭贴图`（关闭并进入可恢复历史）/ `销毁贴图`（直接永久清除）

## 分组、持久化与恢复机制

- **数量约束**：全局最多保留 `32` 张活跃（未关闭）贴图、最多 `128` 张总存储贴图（活跃与已关闭合计），其中已关闭贴图保留上限由 `pin-closed-limit` 控制（默认 `1`，可设 `0–128`）。
- **存储策略**：在 `首选项 -> 贴图 -> 行为` 通过 `pin-storage`（`仅在内存中保存贴图` 开关）切换仅保留在内存或跨重启持久化到 `$XDG_DATA_HOME/clivuu/pins/`。持久化后的已关闭贴图会卸载位图内存占用，待恢复时按需重新加载。
- **贴图分组**：可通过系统托盘 `贴图组` 子菜单、贴图右键 `移动到贴图组`、图形化贴图组管理窗口（`clivuu show-group-manager`）、快速切换器（`clivuu switch-groups`）或命令行（`create-group`、`switch-group`、`switch-group-prev`、`rename-group`、`delete-group`、`remove-empty-groups`、`empty-group`、`groups`）管理工作区。分组支持可选颜色标记、上下排序、清除空组以及删除分组时迁移或销毁组内贴图；切换分组时，其他分组的贴图仅隐藏而不会被关闭。

## Wayland 与 GNOME 焦点行为

- **原生 Wayland（`niri`、`Hyprland`、KDE）**：贴图以 `gtk4-layer-shell` 的 `ON_DEMAND` 表面呈现，活动贴图边界显示主题强调色阴影。
- **GNOME Wayland**：由于 GNOME 不支持 `wlr-layer-shell`，贴图通过 XWayland 呈现。`pin-gnome-focus` 默认开启（`true`），确保贴图响应方向键微调、`1–6` 变换以及带修饰键的滚轮手势。若希望贴图始终不抢占焦点（例如保持 `dash-to-panel` 自动隐藏面板稳定显示），可在 `首选项 -> 贴图 -> 行为` 关闭 `pin-gnome-focus`（`允许贴图获取键盘焦点`）；关闭后包括展开工具栏期间在内均不获取键盘焦点或响应快捷键，可通过鼠标与工具栏按钮操作，且指针移出普通贴图时自动取消其激活态。
