# 区域录屏与回放

[使用手册](../README.md) | [English](../../en/guide/recording.md) | **简体中文**

Clivuu 将选定区域的屏幕画面录制为无损中间视频流（Matroska 容器内的 `VP9` Y444），并将系统声音与麦克风分别保存为独立的 `48 kHz` 立体声无损 `FLAC` 音轨，停止后可先裁剪时间轴、裁切画面边框、调速和平衡双路音量，再按需导出为 `MP4`、`WebM` 或 `GIF`。

## 启动方式

- **托盘菜单**：点击 `Region recording`，框选录屏范围松手后直接显示就绪控制栏。
- **截图工具栏**：在交互式截图选好区域后点击 `Region recording` 或按 `V`。
- **命令行**：
  - `clivuu record`（交互框选后进入就绪控制栏）
  - `clivuu record --area X Y W H`（跳过就绪等待，直接按指定坐标以 `Quick` 模式开始录制）
  - `clivuu record --area X Y W H -o FILE.mp4|FILE.webm|FILE.gif`（同样进入 `Quick` 模式并在停止后导出对应格式）
  - 录制过程中控制：`clivuu pause-recording`、`clivuu stop-recording`，或托盘菜单中的 `暂停录制` / `继续录制` 与 `停止录制`。

## 就绪控制栏参数

开始录制前，可通过拖拽选区边角或 `移动录制区域` 按钮微调范围，按 `Enter` 开始录制或按 `Esc` 直接放弃，也可在可拖动悬浮工具栏中配置以下参数：

- **帧率（FPS）**：`5`、`16`、`24`（默认）、`30`、`60`。
- **倒计时（Delay）**：`0`、`1`、`2`、`3`、`5`、`10` 秒。
- **模式**：
  - `普通录制`（`Normal`）：停止后打开无边框回放编辑器，检查并编辑后再导出。
  - `快速录制`（`Quick`）：停止后跳过回放界面，直接按快速保存配置导出为 `MP4`。
- **光标与音轨开关**：
  - `显示鼠标光标`（默认开启，独立于截图中的 `capture-cursor` 设置）
  - `系统声音`（检测到系统监听器音频设备时默认开启）
  - `麦克风`（检测到麦克风输入设备时默认开启）

点击开始录制后，全部就绪设置（帧率、倒计时、模式、选区位置与尺寸、光标及音轨开关）即锁定。若在就绪栏、倒计时、portal 授权框取消或确认放弃录制，应用直接退出而不弹出错误通知。

## 录制期界面与缓存策略

- 录制开始后，位于或遮挡录制区域内部的控制条会自动隐藏（包含拖动过程中的临时界面），此时仍可通过托盘或 CLI 命令暂停和停止。
- **暂停与恢复**：暂停经过的挂钟时长会从最终时间轴和编码时间戳中剔除。
- **录制策略**（`首选项 -> 保存 -> 录制 -> 录制策略`）：
  - `内存优先`（`temporary`，在 `/tmp` 缓存中间流，上限由 `recording-temp-limit-mib` 控制，默认 `512 MiB`，可设 `16–16384 MiB`）：接近上限或可用空间不足 `16 MiB` 时安全停止采集，仍可进入回放并保存。
  - `视频目录`（`direct`）：直接将中间流写入设定的视频保存目录（`video-directory`），避免长时长录屏占用过多内存。

录制中点击重新开始或放弃时会先请求二次确认，避免误删已采集素材。

## 回放编辑器（`普通录制` 模式）

停止 `Normal` 模式录制后，屏幕会在原录制区域弹出无边框回放播放器：

- **播放 / 暂停**：点击播放按钮、点击视频画面内部或按 `Space`。
- **时间轴剪辑**：拖动进度条两端的裁剪手柄截取有效片段。
- **画布裁切**：直接拖动回放画面的四边或四角即可裁切输出像素（无损中间源按原生源像素裁切，不预先降采样）。
- **倍速设置**：支持 `0.2x`、`0.25x`、`0.5x`、`0.75x`、`0.8x`、`1.0x`、`1.25x`、`1.5x`、`1.75x`、`2.0x`。
- **分轨混音**：在 `录制音频` 面板中独立调节 `系统声音` 与 `麦克风` 音量（`0%–200%`，点击 `%` 读数恢复 `100%`）或单独静音。
- **重置编辑**：清除裁剪、裁切、倍速和双轨音量调整，恢复原始录制片段。
- **导出与完成**：
  - 支持格式：`MP4`（H.264/MPEG-4 + AAC）、`WebM`（VP9 + Opus）及 `GIF`（静默动画；导出 GIF 不会删除保留的双路原始音轨，仍可再次导出带声视频）。
  - **保存录制**（`Ctrl+S` 打开原生 GTK 保存框）与 **快速保存**（`Ctrl+Shift+S` 直接写入快速保存目录）作为两个独立按钮提供。
  - **复制文件**（`Ctrl+C`）：导出并将视频文件 URI 复制到剪贴板。
  - **重新录制**与 **关闭回放**（`Esc`）：无论之前是否已导出过文件，点击重新录制或关闭都会弹窗确认是否丢弃当前素材与编辑；若导出中途失败或取消，原始中间素材仍保留，可修改路径或格式后重试。
