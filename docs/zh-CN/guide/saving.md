# 保存、命名模板与桌面通知

[使用手册](../README.md) | [English](../../en/guide/saving.md) | **简体中文**

Clivuu 提供手动保存（单一 Clivuu 管理的原生 GTK 对话框）、一键快速保存以及截图自动备份三种机制，并在图片与录屏间共用同一套文件名模板解析器。

## 保存模式对比

| 模式 | 触发方式 | 行为说明 |
| :--- | :--- | :--- |
| **手动保存** | `Ctrl+S`、工具栏 `Save image`、贴图右键 `Save image` 或回放 `Save` | 打开原生 GTK 保存框并预填扩展后的手动命名模板；切换 PNG、JPEG 或视频格式时，文件名后缀会在当前对话框内即时同步刷新 |
| **快速保存** | `Ctrl+Shift+S`、`-o quick-save` 或 `Quick` 录屏模式 | 不弹出确认窗口，直接写入 `image-quick-directory`（默认 `$XDG_PICTURES_DIR/Clivuu`）或 `video-directory`（默认 `$XDG_VIDEOS_DIR/Clivuu`） |
| **自动保存（图片）** | 开启 `image-auto-save=true` 时 | 当截图通过复制到剪贴板、贴图或手动保存正常结束时，自动向 `image-auto-directory` 额外留存一份副本；取消截图不会生成副本 |

若快速保存或自动保存目录不存在，Clivuu 会自动创建；文件名冲突时在快速/自动保存模式下自动追加编号递增，不覆盖已有文件。

## 支持格式与压缩质量

- **图片格式**：支持 `PNG`（`.png`）与 `JPEG`（`.jpg` 或 `.jpeg`）。选择 `JPEG` 时默认后缀为 `.jpg`，但会保留手动键入的 `.jpeg`，最终写入的文件字节格式始终与确认后的扩展名严格一致。
- **图像质量（`image-quality`）**：统一使用 `0–100`（默认 `100`）。对于 PNG，`100` 使用快速无损模式，`0–99` 启用自适应压缩；对于 JPEG 控制压缩品质 `1–100`（透明像素先铺白底合成）。
- **记忆上次手选格式（`image-remember-extension`）**：默认开启，下次打开手动保存框时沿用上次选择的扩展名。
- **视频格式**：回放编辑器支持导出 `MP4`、`WebM` 与 `GIF`；`Quick` 模式默认直接写入 `MP4`。

## 文件名模板变量

在 `首选项 -> 保存` 设置各类模板（`image-manual-name`、`image-quick-name`、`image-auto-name`、`video-manual-name`、`video-quick-name`）。默认模板均为 `Clivuu_$yyyy-MM-dd_HH-mm-ss$`，无需填写扩展名（预览与导出会自动补齐图片 `.png` / 录屏 `.mp4`）。`$...$` 内的日期时间串支持连写分隔符，也可以写成包含相对子目录的路径（如 `$yyyy$/$MM$/Clivuu_$HH$$mm$$ss$`）；任何试图跳出目标目录的路径（如 `..` 或绝对路径前导 `/`）都会被校验拒绝。

| 模板标记 | 含义 | 示例输出 |
| :--- | :--- | :--- |
| `$yyyy$` / `$yy$` | 4 位 / 2 位年份 | `2026` / `26` |
| `$MMMM$` / `$MMM$` / `$MM$` / `$M$` | 月份（英文全称 / 英文缩写 / 补零数字 / 数字） | `November` / `Nov` / `11` / `11` |
| `$dddd$` / `$ddd$` / `$dd$` / `$d$` | 星期与日期（英文星期全称 / 缩写 / 补零日 / 日） | `Saturday` / `Sat` / `14` / `14` |
| `$HH$` / `$H$` | 小时（`00–23` / `0–23`） | `09` / `9` |
| `$mm$` / `$m$` | 分钟（`00–59` / `0–59`） | `05` / `5` |
| `$ss$` / `$s$` | 秒（`00–59` / `0–59`） | `08` / `8` |
| `$zzz$` / `$z$` | 毫秒（`000–999` / `0–999`） | `042` / `42` |
| `$t$` | 区域时段标识 | `AM` |
| `$uuid$` | 随机 UUID v4 | `550e8400-e29b-41d4-...` |
| `$unix$` / `$unix_ms$` | Unix 秒级 / 毫秒级时间戳 | `1794614400` |
| `%username%` | 当前操作系统用户名 | `alex` |
| `%computername%` | 当前主机名 | `workstation` |
| `%os%` | 操作系统名称 | `linux` |

将鼠标悬停在 `首选项 -> 保存` 中文件名输入框右侧的信息按钮上可查看提示，点击该按钮会直接弹出 **命名规则** 对话框以便查看和复制模板标记。

## 桌面通知与“在文件中显示”

开启 `image-save-notify` 或 `video-save-notify` 后，保存成功将发送系统通知展示文件名与路径：

- 图片保存通知会附带已保存截图的缩略图预览。
- 点击通知按钮（随桌面系统语言显示为 **在文件中显示** / **Show in Files**）会通过 D-Bus `org.freedesktop.FileManager1` 打开所在目录并高亮目标文件，不支持该接口的环境则回退到默认目录打开器。
