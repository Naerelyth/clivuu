# 画布标注与编辑

[使用手册](../README.md) | [English](../../en/guide/annotations.md) | **简体中文**

Clivuu 在交互式 [屏幕截图](capture.md) 与 [桌面贴图](pins.md) 编辑时共用同一套标注引擎与工具栏。截图模式下可以直接在选区外侧起笔标注；后续扩大选区时，外部标注会完整显示，最终导出自动按实际选区裁剪。

## 主工具栏与工具快捷键

主工具栏保持固定 `32 px` 高度，左侧带有可拖拽手柄（`移动工具栏`），功能按分隔线分组，点击各标注工具会即时展开对应宽度的紧凑次级选项栏（绘制标注、马赛克打码、擦除或调整已有标注期间，主工具栏与次级选项栏均保持可见，仅在框选、平移、缩放截图选区或按 `Space` 切换时隐藏）：

| 工具 | 快捷键 | 次级选项栏内容 | 使用特点 |
| :--- | :--- | :--- | :--- |
| **指针** | `Ctrl+1` | 无 | 选中并移动/调整**文字**与**序号**标注；贴图下直接拖动窗口，截图下平移选区或拖外侧扩展边界 |
| **形状** | `Ctrl+2` | 线宽（`1–16`）、填充切换、矩形/椭圆切换、颜色 | 按住 `Shift` 绘制正圆或正方形；刚绘完未取消选中前可移动/缩放/旋转（按 `Shift` 以 `15°` 吸附），落地后锁定 |
| **箭头** | `Ctrl+3` | 线宽（`1–16`）、11 种箭头样式、5 种线型、颜色 | 按住拖拽画单段箭头，或点按连续绘制多段折线箭头（右键/双击/`Enter` 结束，`Esc` 取消）；按住 `Shift` 以 45° 步进对齐，未取消选中前可拖动各顶点，落地后锁定 |
| **画笔** | `Ctrl+4` | 线宽（`1–50`）、颜色 | 自由曲线绘制；落笔后保持原笔宽且固定在画布位置不可拖拽移动 |
| **高亮** | `Ctrl+5` | 线宽（`4–50`）、自由/直线/矩形/椭圆切换、颜色 | 半透明荧光标记（默认约 32% 不透明度）；按住 `Shift` 约束直线为 45°、矩形/椭圆为正方形/正圆；自由画笔落笔即固定，几何高亮取消选中落地后锁定 |
| **序号** | `Ctrl+6` | 起始序号设定/步进（`1–9999`）、5 种外观选择、数字格式、大小（`1–50`）、编号与填充色 | 点击画布放置步骤序号，可拖动拉出或开关引导箭头；落地后仍可随时重新选中与移动 |
| **马赛克** | `Ctrl+7` | 笔刷宽度（`4–50`）、自由涂抹/矩形切换、像素化/模糊切换按钮、强度（`3–24`，默认 `8`） | 遮挡敏感内容或区域；自由涂抹落笔后位置固定，矩形马赛克未取消选中前可移动与缩放、落地后锁定 |
| **文字** | `Ctrl+8` | 字体选择器、字号（`1–72`）、粗体、斜体、描边（无/自动/白/黑/自定义，宽度 `0–8` 默认 `1`）、文字与描边色 | 点击画布原地直接输入文字；落地后仍可随时重新选中、编辑、移动与旋转 |
| **橡皮擦** | `E` | 笔刷宽度（`4–50`）、自由涂抹/矩形区域擦除切换 | 擦除画布上的已有标注而不破坏原始底图；自由擦除落笔即固定，矩形擦除取消选中落地后锁定 |

> **标注落地锁定规则**：自由画笔类标注落笔即固定；形状、箭头、几何高亮、矩形马赛克与矩形擦除在刚完成绘制、尚未取消选中前可微调位置、控制柄与样式，一旦点击空白处、切换工具、开始下一笔或右键取消选中（折线绘制中右键先结束折线），即固定在画布上（仅可通过撤销回退）；唯有 **文字** 与 **序号** 落地后仍可通过 **指针**（`Ctrl+1`）或对应工具随时重新选中、移动与编辑。

工具栏其他常用按钮与快捷键：
- **历史与删除、调宽**：`撤销`（`Ctrl+Z`）、`重做`（`Ctrl+Y`）、不可逆清空全部标注（`Ctrl+Shift+Z`）、删除选中标注（`Delete` / `Backspace`），以及通过 `1`/`[` 减小、`2`/`]` 增大当前工具线宽、字号或矩形马赛克强度。
- **贴图专用几何工具**（仅编辑贴图时显示）：`裁剪`（`Crop`，固定 `1px` 强调色边框与圆环锚点，支持直接拖拽四边/四角向内缩放、框选子区域、内部拖动平移已有裁剪框及八向缩放，应用后保留裁剪区域在屏幕上的对应位置）、`顺时针旋转 90°`（`1`）、`逆时针旋转 90°`（`2`）、`水平翻转`（`3`）、`垂直翻转`（`4`）。切换至其他标注工具会退出未应用的裁剪框。
- **快捷功能**：`识别文字`（`O`；截图下 `Shift+O` 快速复制）、`滚动长截图`（仅截图，`L`）、`区域录屏`（仅截图，`V`）。
- **完成输出**：`取消`（截图下 `Esc` 退出；贴图下撤销本次工具栏会话中未应用的编辑并收起工具栏）、`贴图`（截图下 `Ctrl+T`）或 `应用更改`（贴图下 `Enter`/`Esc`/`Space` 提交并收起）、`保存图片`（`Ctrl+S`）、`复制图片`（截图下 `Enter`/`Ctrl+C`，贴图下 `Ctrl+C`）。

## 箭头样式与线型组合

**箭头**（`Ctrl+3`）将箭头头部形态与线条虚实解耦组合（11 种类型 x 5 种线型）：

- **箭头类型**：`Straight`、`StraightBilateral`、`Line`、`LineBilateral`、`Outline`、`Filled`、`DimensionLine`、`Solid`、`SolidBilateral`、`DimensionArrow`、`PlainLine`（普通直线）。
- **线型**：`Solid`（实线）、`Dash`（虚线）、`Dot`（点线）、`DashDot`（点划线）、`DashDotDot`（双点划线）。实心填充风格 `Filled` 不套用虚线样式。

## 序号徽章

**序号**（`Ctrl+6`）用于在操作指引中按顺序标记步骤：

- **数字格式**：`Decimal`（`1, 2, 3`）、`Roman`（`I, II, III`）、`LowerAlpha`（`a, b, c`）、`UpperAlpha`（`A, B, C`）、`Chinese`（`一, 二, 三`）。
- **外观形状**：点击次级栏中的徽章形状选择按钮，可在 5 种徽章外观（`FilledCircle`、`BorderedCircle`、`OutlineCircle`、`Text`、`RoundedSquare`）之间切换。仅带边框圆 `BorderedCircle` 提供独立的编号文字颜色设置。
- **编号控制**：按 `Z` 增大或按 `X` 减小下一个将要放置的序号（不会影响画布上已放置的序号）；点击次级栏起始序号按钮可直接设定或重置下次序号。放置或撤销序号会自动同步编号计数。
- **编辑已放置序号**：放置时按住拖动即可直接拉出引导线；或选中并悬停某个序号，通过浮现的 `−`/`+` 单独增减编号、删除及显隐引导线按钮调整。拖动主体可移动位置，向外拖动尖端可调整缺口引导箭头或短距三角指示（按 `Shift` 对齐方向），拖回徽章内部则收起引导线。

## 马赛克与高斯模糊控制

- **绘制形态**：支持自由笔刷涂抹与矩形框选（创建后不可转换几何形状；自由涂抹落笔后位置固定，矩形框选在取消选中落地前可移动与调整大小）。
- **处理模式与强度**：点击次级栏效果切换按钮，可在像素化（`Pixelate`）与模糊（`Blur`）之间切换。两种效果共用同一套强度阈值（`3–24`，默认 `8`），切换模式时保留当前强度。
- **滚轮分工**：
  - 在 **自由涂抹** 模式下，画布上滚动鼠标滚轮调整笔刷宽度，强弱通过次级栏滑块控制。
  - 在 **矩形框选** 模式下，画布上滚动鼠标滚轮以 `1` 为步长调整马赛克/模糊强度并实时同步次级栏滑块。
  - 将鼠标悬停在次级栏 **效果强度** 滑块上滚动滚轮时，同样以 `1` 为步长精细调节强度并合并为单步撤销。
- 已绘制完成的自由笔刷（画笔、自由高亮、自由马赛克、自由橡皮擦）均保持落笔时的粗细与位置不变。

## 画布直输文字与输入法支持

文字工具直接在画布上创建与编辑文本：

- 选中 **文字**（`Ctrl+8`）后点击画布即可输入；用文字工具单击已有文本块，或在指针工具（`Ctrl+1`）下双击文本块即可重新编辑，拖动平移，拖动角点控制柄或在文本框内外滚动滚轮调整字号（`1–72`），拖动螺旋手柄旋转（`Shift` 以 `15°` 吸附），点击右上角图标删除。原地打字期间，`Ctrl+Z`/`Ctrl+Y`/`Ctrl+Shift+Z` 用于撤销重做文本框内文字，`Esc` 提交文本（无未上屏预编辑时）。
- 点击字体选择按钮可直接输入关键字搜索本地字体；使用输入法检索且存在未上屏预编辑文本时，首次按 `Esc` 仅清除未上屏输入，无未上屏文本时再按 `Esc` 关闭字体面板且不退出截图。
- 当光标停留在文字输入区、搜索框、数值框或激活了 IBus / Fcitx 输入法候选预编辑状态时，数字键和 `E`、`Z`、`X` 等单键优先作为文字录入，不会误触工具切换。

## 颜色选择与屏幕吸管

支持调色的工具（形状、箭头、画笔、高亮、序号、文字）在次级栏中直接提供 `20` 个快捷色块以及一个方形当前颜色启动按钮：

- 点击次级栏中的快捷色块可直接套用预设颜色。
- 点击方形颜色启动按钮打开完整选色面板：包含 `48` 个基本色块、`16` 个持久化自定义颜色槽位（支持添加到自定义色与右键选槽）、屏幕取色吸管（`Pick screen color`）、二维色相/饱和度面板、明度条与透明度滑块（仅主色可用）、`H`/`S`/`V`/`R`/`G`/`B`/`A` 与 `#RRGGBB`/`#RRGGBBAA` HTML 输入框及复制按钮，以及 `取消`/`确定`。
- 修改颜色会更新当前选中标注（如适用）以及后续新绘制的对象。
