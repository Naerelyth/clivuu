# 滚动长截图

[使用手册](../README.md) | [English](../../en/guide/scrolling-capture.md) | **简体中文**

滚动长截图可将网页、聊天记录、代码文件或宽幅表格按重叠区域拼接为一张完整长图，并在选区旁侧显示实时预览。

## 启动方式

- **从截图进入**：在交互式截图界面拖动框选可滚动内容区域（建议避开固定不动的窗口标题栏与侧边菜单），点击工具栏 `Scrolling capture` 或按 `L`。
- **从命令行启动**：运行 `clivuu scroll` 交互框选，或直接运行 `clivuu scroll --area X Y W H`（可选 `-o pin|clipboard|quick-save|file-dialog|FILE.png|FILE.jpg`）。

## 工具栏与控制项

滚动长截图使用与截图、录屏相同的可拖拽悬浮工具栏：

| 控件 | 作用 |
| :--- | :--- |
| **方向切换（`Vertical` / `Horizontal`）** | 在垂直纵向拼接与水平横向拼接之间切换（切换方向会清空当前已采集拼接状态） |
| **移动截图区域（`Move capture region`）** | 沿当前滚动主轴平移选区位置（纵向模式上下移动、横向模式左右移动），宽高尺寸与正交轴位置保持不变；拖动期间暂停取样 |
| **自动滚动（`Auto-scroll`）** | 通过 `org.freedesktop.portal.RemoteDesktop` 按选区尺度发送闭环比例平滑脉冲，触底后自动退出 |
| **裁剪长图（`Trim scrolling capture`）** | 按当前实时画面所在位置手动修剪首尾（纵向模式提供 `裁去当前视图上方` / `裁去当前视图下方`，横向模式提供 `裁去当前视图左侧` / `裁去当前视图右侧`），并可切换 `回滚时自动裁剪`（`scroll-auto-crop`） |
| **重置长截图（`Reset scrolling capture`，`Ctrl+R`）** | 无需退出重新框选即可在当前选区恢复：`从当前画面继续`（保留已拼接内容并以当前画面作为新基准继续采样）或 `在当前选区重截`（`Ctrl+R` 快捷键直达，清空并重新抓取首帧） |
| **编辑（`Edit`）** | 直接在打开工具栏的 [桌面贴图](pins.md) 中编辑已拼接长图 |
| **贴图（`Pin image`，`Enter`）** | 将拼接结果固定到桌面 |
| **保存（`Save image`，`Ctrl+S` / `Ctrl+Shift+S`）** | 弹出原生 GTK 保存框或快速保存 |
| **复制（`Copy image`，`Ctrl+C`）** | 复制到剪贴板 |
| **取消（`Cancel`，`Esc`）** | 放弃并退出滚动长截图 |

## 手动滚动与自动滚动

- **手动滚动（默认）**：在选区范围内用鼠标滚轮、触摸板或拖动滚动条滚动内容。相邻画面保持约 `20%–40%` 重叠率有助于在重复列表排版中精准定位。
- **自动滚动**：点击按钮后按系统提示授予 `RemoteDesktop` 输入控制权限，Clivuu 将按 `scroll-interval` 间隔发送闭环比例平滑滚动脉冲（数值设置 `300–3000 ms`，默认 `700 ms`，运行时安全区间 `150–5000 ms`，选区主轴跨度小于 `220 px` 时自动缩短间隔）；若在不少于 `120 px` 的选区上平滑滚动未产生位移，会自动回退到离散滚轮步进。鼠标指针移出截图矩形、或者停留在 Clivuu 工具栏、提示条、预览条以及打开的弹窗上方时，自动滚动会自动暂停。若桌面拒绝或不支持输入注入，手动滚动仍可正常完成采集。

## 实时预览与拼接保障

当选区外侧屏幕空间充足时，Clivuu 会在旁侧渲染整张长图的缩略预览：

- **绿色视口框**：指示当前实时画面在整个长图拼接文档中所处位置。
- **UI 污染隔离**：移动 Clivuu 工具栏或拖动选区位置时会暂停采样，工具栏、选区边框和提示条均不会进入成片图像。
- **失配恢复、重置与自动裁剪**：若滚动步幅过大导致无重叠，或中途展开折叠内容、切换视图导致画面突变，先前已提交的长图始终保持可导出状态。除反向回滚找回重叠外，还可点击 `重置长截图` 选择 `从当前画面继续`，或按 `Ctrl+R` 执行 `在当前选区重截`。开启 `回滚时自动裁剪`（`scroll-auto-crop`，默认关闭）后，向反方向回滚时会自动裁去多截的首尾部分。

## 限制与配置项

- **保留关键帧上限（`max-scroll-frames`）**：`2–200`（默认 `40`），在 `首选项 -> 截屏 -> 行为` 调整。
- **自动滚动间隔（`scroll-interval`）**：`300–3000 ms`（默认 `700 ms`）。
- **回滚时自动裁剪（`scroll-auto-crop`）**：默认 `false`，工具栏裁剪浮层开关与 `首选项 -> 截屏 -> 行为` 同步。
- **尺寸与导出上限**：滚动主轴选区最小 `48 px`，最大拼接长度 `65,535 px`，内部长图缓存上限 `128 MiB`，并遵循通用导出上限（`48 MP` 像素与 `64 MiB` PNG 缓冲区）。
