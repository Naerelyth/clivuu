# 屏幕截图

[使用手册](../README.md) | [English](../../en/guide/capture.md) | **简体中文**

标准截图会抓取当前桌面画面并在全屏遮罩层中冻结显示，你可以在不打断底层窗口状态的前提下完成区域框选、放大取色、标注、贴图、文字识别、保存或复制。

## 启动方式

- **托盘菜单**：选择 `截图`、`窗口截图`，或 `贴图恢复与清理 -> 贴图最近截图`。
- **命令行**：
  - `clivuu snip`（进入交互式框选）
  - `clivuu snip --window` 或 `--active-window`（单帧窗口截图）
  - `clivuu snip --active-screen` / `--full` / `--last` / `--area X Y W H` / `--size W H`
  - `clivuu snip --delay SECONDS`（延迟 0–3600 秒后再抓帧）
  - 可选 `-o`（`--output`）输出目标（`clipboard`、`pin`、`quick-save`、`file-dialog`、`ocr_clipboard`、`printer`、`barcode`、`no-auto-save`、`success`、`silent` 或 `FILE.png`/`FILE.jpg`/`FILE.jpeg`）；配合非交互范围参数时跳过编辑界面直接完成输出，交互模式下则在确认完成时应用。

## 选区框选与导航

进入截图界面后可以使用以下控制方式：

- **自由框选**：按住左键拖动框出截图区域。
- **选区外扩展边界**：在指针工具（`Ctrl+1`）模式下，点击已有选区外侧可直接将该侧边缘延伸到指针位置。
- **滚轮切换窗口与屏幕**：开始拖动框选前滚动鼠标滚轮，可循环预览指针下方的候选窗口或显示器区域（Hyprland 通过 `hyprctl`、niri 通过 `niri msg` 获取窗口矩形；其余 Wayland 合成器提供显示器边界或使用 `--window` 调用系统窗口选择器）。
- **全屏幕 / 全桌面切换（`Ctrl+A`）**：在当前所在显示器与跨屏合并桌面之间切换。
- **恢复上次区域（`R`）与历史选区（`Page Up` / `Page Down`）**：`R` 快速恢复上一次的截图选区，`Page Up` / `Page Down` 在历史选区记录中前后切换。
- **源像素级微调**：
  - 指针模式（未激活绘图工具）下，直接按方向键每次整体移动选区 `1` 个源像素。
  - `Ctrl + 方向键` 将对应方向边界向外扩张 `1` 个源像素，`Shift + 方向键` 将该方向边界向内收缩 `1` 个源像素（标注编辑过程中同样有效）。
- **逐级退回与直接取消（右键 / `Esc`）**：
  - **鼠标右键**按优先级逐级退回：结束多段折线箭头绘制 -> 取消当前激活标注选中 -> 退出交互 OCR -> 清空已确认选区及其标注并回到待框选状态 -> 无选区时直接退出截图（不记入历史）。
  - **`Esc`** 直接退出截图且不记入历史（存在弹出面板或字体搜索、正在输入画布文字、正在绘制折线或处于交互 OCR 选字状态时，优先处理或退出当前子状态）。

## 遮罩提示与工具栏排布

- **主工具栏与子工具栏整体避让**：选区确定后放置 `32 px` 主工具栏时，会先预留当前活动子工具栏高度（`4 px` 间距 + `32 px` 高度）再判断放在选区下方或上方。若选区底部空间仅能放下主工具栏而放不下子工具栏，主/子工具栏会一起移到选区上方（子工具栏叠在主工具栏之上），避免子工具栏向上翻转压住选区底边；上下都不够时退回选区内部（默认优先 `InsideBottom`）。手动拖拽工具栏手柄固定位置时，子工具栏默认挂在下方并在靠底边时自动翻至上方。
- **左上方像素尺寸指示器（`W × H px`）**：在选区左上角上方显示当前选区的实际像素宽高（启用 `capture-hide-1x1=true` 时拖动前隐藏 `1 × 1` 读数）。选区确认后，指针悬停到像素指示器上方时会自动隐藏，避免遮挡标注绘制或左上角像素，指针移开后恢复显示。
- **左下角快捷键提示（`tips`）**：启用 `capture-show-tips=true`（默认）时，在当前显示器左下角（内缩 `12 px`）按未框选、已框选与标注中显示对应快捷键。拖拽框选或标注手势期间、OCR 模式下以及单窗截图时隐藏，已确认的选区与提示区域重叠时也会自动隐藏，选区移开后恢复。

## 放大镜与像素取色

在尚未确认选区前、初次拖动框选、调整选区边界、在指针模式（`Ctrl+1`）下静止悬停于已选区域内部（且未压在工具栏、弹窗、OCR 选区或标注目标上）以及按住 `Alt` 期间，指针旁会显示实时像素放大镜，并在分数缩放与混合 DPI 显示器环境下保持中心采样像素与十字准星对齐。

- **`Shift`（放大镜显示时）**：在 `RGB` 与 `HEX` 颜色格式之间切换显示。
- **`C`**：在放大镜显示期间复制中心像素的颜色值到剪贴板。
- **`Alt`**：按住期间强制显示放大镜，并在框选前切换全屏十字线、框选后切换边缘与中心对齐参考线。

## 画面刷新、历史回溯与输出动作

- **刷新底图（`F5`）**：针对普通桌面截图重新抓取最新静态画面（若启用 `capture-cursor=true` 会一并更新光标），同时保留当前选区和已有标注。
- **浏览历史截图（`,` 与 `.`）**：逗号（`,`）与句号（`.`）在匹配当前显示器布局的内存截图历史中前后切换（环形缓冲区上限为 `128 MiB`，默认保留最近 `20` 条，由 `capture-history-records` 控制）。
- **快捷结束操作**：
  - `Enter`、`Ctrl+C` 或在指针模式下双击选区内空白处（非文字对象上）：复制选区结果并退出截图。
  - `Ctrl+T`：将当前选区直接贴图到桌面。
  - `Ctrl+S`：打开原生 GTK 文件保存对话框。
  - `Ctrl+Shift+S`：按设置中的目录与命名模板直接快速保存。
  - `O` / `Shift+O`：默认（`ocr-quick-copy=false`）按 `O` 在选区内原位开启交互式 OCR 选字（采用已配置的 `PP-OCRv5` 或系统 `Tesseract` 离线引擎，开启 `ocr-quick-copy=true` 时则直接复制并退出）；按 `Shift+O` 始终直接识别整块并复制后退出。
  - `L`：直接以当前选区进入 [滚动长截图](scrolling-capture.md)。
  - `V`：直接以当前选区进入 [区域录屏](recording.md)。
  - `Space`：显示或隐藏编辑工具栏与次级选项栏。

## 采集后端行为

- **普通截图**：所有会话下均非交互调用 `org.freedesktop.portal.Screenshot` 获取静态帧，并在 Clivuu 遮罩层内裁切与渲染。
- **包含光标截图**：在 `首选项 -> 截屏 -> 行为` 开启 `capture-cursor` 后，Wayland 会话通过 `ScreenCast` 抓取含鼠标光标的单帧并在进入标注前关闭流，X11 会话通过 XFixes 合成光标图像。GNOME Wayland（基于 `org.gnome.Mutter.ScreenCast`）与原生 X11 的交互截屏还会同步保留同源无指针底图，框选后按 `` ` `` 或 `!` 可就地切换真实位置光标的显隐。
- **窗口截图（`--window` / `--active-window`）**：在所有桌面环境下统一调用系统 `ScreenCast` 窗口选择器抓取单帧后关闭视频流，再进入标注界面。
- **画面保护上限**：单次采集与导出限制最大像素为 `48 MP`（`48,000,000` 像素），单文件编码传输上限 `64 MiB`。
