# 快捷键与鼠标手势

[使用手册](../README.md) | [English](../../en/guide/shortcuts.md) | **简体中文**

交互界面内的按键绑定由 Clivuu 直接处理；触发截图、贴图、长截图与录屏的全局快捷键需要在桌面环境或窗口管理器中绑定对应的 `clivuu` 命令。

## 全局命令绑定

常用全局绑定示例见 [快速入门](getting-started.md#桌面集成与全局快捷键) 与 [命令行与 D-Bus 控制](../development/cli.md)。

## 标注工具与共用编辑快捷键

以下快捷键同时适用于截图覆盖层与展开了工具栏的贴图（当聚焦文字输入框、搜索框、数值框或激活输入法预编辑时，常规输入字符优先交给文本录入）：

| 操作 | 快捷键 | 说明 |
| :--- | :--- | :--- |
| 指针工具 | `Ctrl+1` | 重新选中并移动/编辑文字与序号标注；贴图下拖动贴图，截图下选区外拖可扩展选区边界 |
| 形状工具（矩形 / 椭圆） | `Ctrl+2` | 绘制时按住 `Shift` 约束为正方形或正圆（取消选中落地后锁定） |
| 箭头工具 | `Ctrl+3` | 支持拖拽画单段箭头与点按画折线箭头（右键/双击/`Enter` 结束，`Esc` 取消）；按住 `Shift` 以 45° 增量吸附方向 |
| 画笔工具 | `Ctrl+4` | 自由手绘曲线（落笔后位置固定不可拖拽） |
| 高亮工具 | `Ctrl+5` | 自由手绘、圆角直线、矩形或椭圆荧光高亮（按住 `Shift` 约束 45° 直线或正方形/正圆） |
| 序号工具 | `Ctrl+6` | `Z` / `X` 单独增减下一个序号数字 |
| 马赛克工具 | `Ctrl+7` | 点击效果图标切换像素化/模糊；滚轮控制矩形强度（或滑块悬停步长 `1`）及自由涂抹笔宽 |
| 文字工具 | `Ctrl+8` | 画布原地输入；`Esc` 先清除字体搜索框未上屏输入法预编辑，再关闭字体面板 |
| 橡皮擦 | `E` | 自由涂抹或矩形区域擦除画布上的标注 |
| 删除选中标注 | `Delete` / `Backspace` | 删除当前选中的标注对象 |
| 调节粗细 / 字号 / 马赛克强度 | `滚轮` / `1` / `2` / `[` / `]` | `1` / `[` 减小、`2` / `]` 增大笔宽、字号或矩形马赛克强度 |
| 结束折线 / 取消选中标注 | `鼠标右键` | 结束未完成的折线箭头或取消选中当前标注 |
| 约束图形比例与方向 | `Shift` | 形状与高亮对齐正圆/正方形，箭头与引导线以 `45°` 吸附，旋转以 `15°` 吸附 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` | 分步撤销或重做标注操作（文字框输入期间作用于文本框编辑） |
| 清空全部标注 | `Ctrl+Shift+Z` | 不可逆地清空当前图片上所有标注（文字框输入期间作用于文本框编辑） |
| 保存 / 快速保存 | `Ctrl+S` / `Ctrl+Shift+S` | 弹出原生 GTK 保存框或直接写入快速保存目录 |
| 复制图片 | `Ctrl+C` | 复制含标注的结果图像到剪贴板（截图下也可按 `Enter` 完成复制） |
| 显示 / 隐藏工具栏 | `Space` | 切换工具栏显示（在贴图上同时应用待确认修改） |

| :--- | :--- | :--- |

| 切换当前屏幕 / 全桌面 | `Ctrl+A` | 快速覆盖当前屏幕或联合全桌面 |
| 恢复上次选区 | `R` | 还原上次成功截图的矩形区域 |
| 浏览选区历史 | `Page Up` / `Page Down` | 前后切换记录的选区位置 |
| 浏览截图画面历史 | `,` / `.` | 在匹配当前显示器布局的最近内存截图中前后翻页 |
| 显示 / 隐藏已捕获指针 | `` ` `` / `!` | 开启 `capture-cursor=true` 时，在截屏选区期间动态切换真实位置的鼠标指针显隐（支持 GNOME Wayland 与原生 X11） |
| 刷新静态底图 | `F5` | 对普通桌面截图重新抓取画面并保留当前选区与已画标注 |
| `1` 源像素平移选区 | `方向键` | 指针模式下上下左右整体微调位置 |
| `1` 源像素扩展 / 收缩边界 | `Ctrl+方向键` / `Shift+方向键` | 向外扩张（`Ctrl`）或向内收缩（`Shift`）对应方向边界 |
| 将选区贴图到桌面 | `Ctrl+T` | 立即生成置顶贴图 |

| 快速复制识别文字 | `Shift+O` | 识别选区内文字后直接复制全文并退出 |
| 转入滚动长截图 | `L` | 沿当前选区开始长图拼接 |
| 转入区域录屏 | `V` | 沿当前选区进入录屏就绪栏 |
| 逐级重置选区 / 取消 | `鼠标右键` | 先结束折线/取消标注选中/退出 OCR，再清空选区；无选区时取消截图 |
| 直接取消截图 | `Esc` | 无弹出面板、文字输入、折线或 OCR 状态时直接取消截图 |

## 桌面贴图快捷键

贴图获得键盘焦点时可用（原生 Wayland / X11 下始终可用，GNOME 下在默认 `pin-gnome-focus=true` 时可用；关闭 `pin-gnome-focus` 后包含展开工具栏阶段在内均不接收键盘快捷键）：

| 操作 | 快捷键 | 说明 |
| :--- | :--- | :--- |
| `1 px` 移动贴图 | `方向键` | 未激活绘图工具时按逻辑像素微调位置 |
| 顺/逆时针旋转 `90°` | `1` / `2` | 未激活绘图工具时旋转显示与导出方向 |
| 水平 / 垂直翻转 | `3` / `4` | 未激活绘图工具时镜像贴图内容 |
| 切换灰度 / 反色滤镜 | `5` / `6` | 未激活绘图工具时切换可逆滤镜（导出同步应用） |
| 键盘缩放 / 调透明度 | `+` / `=` / `-` | 使用与滚轮缩放/透明度一致的修饰键（含小键盘 `+`/`-`，需启用对应配置项） |
| 全选当前分组可见贴图 | `Ctrl+A` | 批量移动、滤镜变换、合并复制/保存、关闭或销毁 |
| 用剪贴板替换内容 | `Ctrl+V` | 原地替换当前贴图，保留屏幕位置 |
| 复制原始未栅格化文字 | `Ctrl+Shift+C` | 从文本、HTML 或色卡贴图复制源文本 |
| 原位识别文字（OCR） | `O` | 未激活绘图工具时切换原位选字模式（`Ctrl+C` 复制、`Ctrl+A` 全选、`Esc` 取消选择/退出、双/三击选行/段、按住 `Alt` 拖动贴图） |
| 打开首选项 | `Ctrl+Shift+P` | 启动或前置设置窗口 |
| 应用更改并收起工具栏 | `Enter` / `Esc` / `Space` | 应用修改并收起工具栏（撤销未应用修改请点工具栏 `取消` 按钮） |
| 关闭贴图 | `Ctrl+W` / `Esc`（工具栏收起时） | 移入可恢复的已关闭历史 |
| 永久销毁贴图 | `Shift+Esc` | 直接彻底移除 |

| 操作 | 快捷键 | 说明 |

| 显示 / 隐藏放大镜与参考线 | `Alt` | 在截图与聚焦贴图上按住临时显示放大镜；截图下同时在框选前切换全屏十字线、框选后切换对齐参考线 |

## 长截图、区域录屏与回放

- **滚动长截图**：`Enter`（贴图）、`Ctrl+C`（复制）、`Ctrl+S` / `Ctrl+Shift+S`（保存 / 快速保存）、`Ctrl+R`（在当前选区清空重截）、`Esc`（取消）。
- **区域录屏**：`Enter`（就绪状态开始录制）、`Esc`（就绪状态直接放弃，录制中或暂停时打开丢弃确认提示）。
- **录屏回放编辑器**：`Space`（播放 / 暂停）、`Ctrl+C`（复制导出文件）、`Ctrl+S` / `Ctrl+Shift+S`（保存 / 快速保存）、`Esc`（打开关闭确认弹窗）。

## 自定义贴图鼠标手势

在 `首选项 -> 控制 -> 鼠标` 中可调整贴图的鼠标触发行为：

| 配置键 | 默认绑定 | 动作 |
| :--- | :--- | :--- |
| `pin-mouse-zoom` | `wheel` | 缩放贴图尺寸（可选 `wheel` 或 `none`，支持最多 2 个修饰键） |
| `pin-mouse-opacity` | `ctrl+wheel` | 调节贴图透明度 |
| `pin-mouse-close` | `double-left` | 关闭贴图（可选 `double-left`、`middle`、`right` 或 `none`） |
| `pin-mouse-reset` | `middle` | 重置缩放与透明度 |
| `pin-mouse-thumbnail` | `shift+double-left` | 缩略图与完整尺寸切换 |
| `pin-mouse-copy-text` | `shift+right` | 复制原始文本 |
| `pin-mouse-destroy` | `ctrl+double-left` | 永久销毁贴图 |
| `pin-mouse-zoom-keys` / `pin-mouse-opacity-keys` | `true` / `true` | 允许配合相同修饰键使用 `+`、`=`、`-`（及小键盘 `+`/`-`）执行缩放或调透明 |

每次触发最多绑定两个修饰键（`ctrl`、`shift`、`alt`、`super`），匹配时要求修饰键完全一致且按列表先后顺序优先。点击该页 `重置设置` 仅恢复 `控制 -> 鼠标` 的默认设置。
